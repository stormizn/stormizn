## ⚡ A bit about me

Self-taught developer from **Lucknow, India**. I started programming in 2021 because I wanted to build something inside my favourite game — Java was the way in, and I never really left.

Today most of my time goes into **Minecraft server internals**: Spigot and Paper plugins with custom mechanics, Minestom experiments, and the kind of debugging that only shows up once the server is actually live. Outside of that I build **Discord bots**, **Spring Boot APIs**, and small web apps — usually because I wanted a tool that didn't exist yet.

- 🔭 **Building** — [MC Revamp](https://portfolio-stormizn.vercel.app/projects), a modern Minecraft PvP network on Minestom
- 🌱 **Learning** — Rust, Kotlin, React/Next.js, and deeper NMS
- 🧠 **Working theory** — if it only works on localhost, it doesn't work yet
- 🖥️ **Setup** — Windows, IntelliJ IDEA, too many terminals open
